# Настройки

Всё находится в меню значка Moody Dimmer в строке меню. Изменения применяются сразу и запоминаются. Меню доступно на
английском, русском и испанском. Пункты с галочками переключаются, не закрывая меню, поэтому можно поменять несколько
подряд.

## По умолчанию

| Настройка | По умолчанию |
|---|---|
| Эффект вкл/выкл | включён |
| Оставлять ярким | Все окна приложения |
| Убирать эффект при перетаскивании | включено |
| Затемнять строку меню | включено |
| Затемнение / Размытие / Зерно | 50 % / выкл / выкл |
| Анимация | 150 мс |
| Сочетание клавиш | ⌃⌥⌘D |
| Переключать встряхиванием курсора | включено |
| Значок в строке меню | Каскад, тема «Как в системе» |
| Язык | Как в системе |
| Запускать при входе | выключено |

## Переключатель Moody Dimmer

Переключатель вверху меню включает и выключает эффект. Пока он выключен, значок в строке меню приглушён, а
приложение ничего не делает: только ждёт, когда эффект включат переключателем, сочетанием клавиш или встряхиванием
курсора.

## Дать доступ Accessibility…

Пункт виден, только пока у Moody Dimmer нет доступа Accessibility. Открывает «Системные настройки →
Конфиденциальность и безопасность → Универсальный доступ». Без доступа эффект следует за переключением между
приложениями, но не за сменой окон внутри одного приложения (диалоги, второе окно, перемещение окон).

## Оставлять ярким

Что остаётся ярким, пока всё остальное затемнено:

- **Только активное окно**: только переднее окно активного приложения. Строгий фокус на одном окне.
- **Все окна приложения**: все видимые окна активного приложения, чтобы диалог или панель не затемняли главное окно
  приложения. Окна других приложений поверх них остаются затемнёнными.

Если у активного приложения нет окон (закрыто последнее или приложение завершилось, а фокус никуда не перешёл),
ярким по тому же правилу остаётся верхнее из оставшихся окон, чтобы они не терялись в затемнённом фоне. На рабочем
столе (активен Finder без окон) и на пустом экране эффекта нет.

## Поведение

- **Убирать эффект при перетаскивании**: когда перетаскиваемое (файл, клип, текст) выходит за окна приложения, из
  которого его тянут, эффект плавно убирается, чтобы было видно, куда отпускать. Возвращается после отпускания
  кнопки мыши.
- **Затемнять строку меню**: эффект затемняет и строку меню. В macOS 26 и новее она прозрачная, поэтому при сильном
  затемнении становится тёмной, а значки на ней могут остаться тёмными. Если выключить, эффект заканчивается у нижнего
  края строки меню. Если строка меню скрывается автоматически, эффект всегда закрывает весь экран.

## Эффект

Три слайдера задают эффекты, и их можно сочетать: **Затемнение** (чёрный слой поверх фона), **Размытие** (размытие
фона) и **Зерно** (статичное плёночное зерно). Слайдер на нуле выключает свой эффект.

## Слайдеры

Слайдер можно тянуть, кликнуть в любое место или прокрутить над ним трекпадом или колёсиком мыши. Текущее значение
показано справа. Значок внутри слайдера движется вместе со значением.

| Слайдер | Диапазон | Как переводится в эффект |
|---|---|---|
| Затемнение | выкл–100 % | непрозрачность чёрного слоя = x (линейно; 100 % — полностью чёрный) |
| Размытие | выкл–100 % | радиус = 50 × x^1.6 pt: 10 % ≈ 1, 30 % ≈ 7, 50 % ≈ 17, 80 % ≈ 35, 100 % = 50 |
| Зерно | выкл–100 % | статичное плёночное зерно, непрозрачность = 0.5 × x^0.75 (слабые значения тоже заметны) |
| Анимация | мгновенно–400 мс | сколько длятся смена фокуса и изменение эффекта; *мгновенно* — сразу |

## Быстрое переключение

Два способа включить или выключить эффект, не открывая меню. Оба работают в любом приложении и не требуют
дополнительных разрешений.

- **Сочетание клавиш**: по умолчанию ⌃⌥⌘D. Нажмите на пункт и введите новое сочетание; в нём должна быть хотя бы одна
  из клавиш ⌘, ⌥ или ⌃. Esc — отмена, Delete — убрать сочетание. Буквы показываются как в латинской раскладке, какая
  бы раскладка ни была включена.
- **Переключать встряхиванием курсора**: быстро потрясите курсором туда-обратно на месте, в любом направлении
  (влево-вправо, вверх-вниз или по диагонали), примерно три быстрых движения туда-обратно. Важна скорость, а не
  размах: подойдёт и короткое покачивание, и взмах примерно на треть экрана, лёгкая дуга тоже не мешает. Одна тряска
  переключает эффект один раз; чтобы переключить снова, сначала ненадолго остановите курсор. Медленные движения
  туда-сюда, круговые движения, зигзаг через весь экран, наведение с промахом и перетаскивание его не вызывают. Если
  не пользуетесь, выключите: тогда приложение совсем перестаёт получать движения курсора.

## Значок в строке меню

- **Стиль**: *Каскад* (яркое окно перед затемнённым) или *Окно* (одно окно).
- **Тема**:
  - *Как в системе*: чёрный в светлой теме, белый в тёмной. Следует за оформлением системы, в том числе в режиме
    «Автоматически» по времени суток.
  - *Светлая*: всегда чёрный, для светлой строки меню.
  - *Тёмная*: всегда белый, для тёмной строки меню.

## Язык

*Как в системе* выбирает первый из английского, русского и испанского среди предпочитаемых языков системы, иначе
английский. Можно выбрать и вручную: *English*, *Русский* или *Español*. Меню переключается сразу, без перезапуска.

## Запускать при входе

Запускает Moody Dimmer при входе в систему.

## Проверить обновления…

Спрашивает у GitHub последнюю версию, только когда вы выбираете этот пункт: сама по себе программа ничего не
проверяет. Пока идёт проверка, рядом с пунктом крутится индикатор, а меню остаётся открытым. Если вышла новая версия,
в окошке будет ссылка на страницу релиза. Если приложение установлено через Homebrew, там же будет команда обновления
(`brew update && brew upgrade moody-dimmer`) и кнопка, чтобы её скопировать. Само приложение ничего не скачивает и не
устанавливает.

## Выход

Завершает Moody Dimmer.

## Когда эффект убирается сам

Для этого настройки не нужны:

- полноэкранные Spaces (видео, плееры, приложения в full screen) и окна без рамки на весь экран (игры);
- Mission Control, App Exposé и «Показать рабочий стол»;
- перетаскивание за пределы исходного приложения (если включено *Убирать эффект при перетаскивании*).
