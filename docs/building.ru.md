# Сборка

## Сборка и установка

Для сборки достаточно Command Line Tools. Если установлен Xcode, иконка приложения собирается в новом формате Icon
Composer.

```sh
./scripts/make-cert.sh             # один раз: локальный сертификат для подписи
./scripts/build-app.sh --install   # сборка, копия в /Applications и перезапуск
```

Каждая сборка создаёт `build/MoodyDimmer-<версия>.dmg` (приложение и ярлык на «Программы»). Без `--install`
собирается только DMG. Сам `.app` собирается во временной папке и после сборки удаляется, поэтому macOS видит один
Moody Dimmer, в /Applications.

## Подпись и доступ Accessibility

`scripts/make-cert.sh` создаёт в связке ключей «Вход» самоподписанный сертификат *Moody Dimmer Local Signing*.
Скрипт сборки подписывает им, поэтому подпись одинакова между сборками и macOS сохраняет доступ Accessibility.

Без сертификата подпись ad-hoc, и доступ сбрасывается после каждой пересборки: удалите Moody Dimmer из «Системные
настройки → Конфиденциальность и безопасность → Универсальный доступ» и выдайте доступ заново.

При первой подписи macOS может спросить, разрешить ли `codesign` использовать ключ. Выберите «Разрешать всегда»,
чтобы запрос не повторялся; пока не ответите, сборка ждёт.

## Иконка приложения

Иконка приложения (тёмная) генерируется кодом. После правок в `scripts/make-icon.swift` пересоздайте её:

```sh
swift scripts/make-icon.swift "$PWD"                                 # → Resources/AppIcon.icon и AppIcon.icns
swift scripts/make-icon.swift "$PWD" --preview "$PWD/Design/AppIcon"  # превью всех вариантов
```

В генераторе сохранены несколько вариантов (cascade, veil, dimmer), каждый в светлой и тёмной теме. Их превью лежат в
`Design/AppIcon`.

Иконка приложения, `Resources/AppIcon.icon`, сделана по гайдлайнам macOS 27: квадратные векторные слои (затемнённое
заднее окно и светлое переднее) на градиентном фоне, без нарисованных теней, свечения и текстуры. Liquid Glass macOS
добавляет сама и сама делает прозрачный и тонированный варианты. Сборка компилирует иконку через `actool` из Xcode,
без Xcode используется `AppIcon.icns` (системная отрисовка той же иконки).
